# Dashboard E-commerce Analysis (Power BI)

## Objectif

Conception d'un dashboard interactif sous Power BI pour analyser les performances d'une activité e-commerce et faciliter la prise de décision.

## Visualisations réalisées

- **KPIs principaux** : Total des ventes (25,16M), nombre de commandes (50K), panier moyen (503,16) et âge moyen des clients (43,97).
- **Ventes par catégorie de produits** : comparaison des revenus entre les 8 catégories (Sports, Toys, Books, Clothing, Electronics, etc.).
- **Évolution des ventes mensuelles** : suivi des tendances sur l'année.
- **Méthodes de paiement** : répartition par type (UPI, PayPal, Carte bancaire, etc.) et par trimestre.
- **Carte géographique** : distribution des ventes par pays (USA, France, Inde, Japon, Australie…).

## Fonctionnalités interactives

Filtres dynamiques par **catégorie de produit** et par **période de transaction**, permettant une exploration flexible des données.

## Outil

Power BI Desktop
